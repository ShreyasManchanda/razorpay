The agreement is not the evidence.

Warden checks whether an agent-to-agent payment was honestly negotiated before it is allowed to move.

Protocols such as AP2, ACP, UPI, and P3P-style systems can prove authorization: the signature is valid and the right key signed it. They cannot tell whether an agent's agreement was obtained honestly. A merchant can hide an instruction in message history or slowly talk a buyer into a purchase it was never authorized to make. Warden evaluates the negotiation itself, not just the resulting signature.

Negotiation: buyer and merchant agents exchange structured turns—offers, counters, accepts, and rejects—building a cart and transcript in real time. Ed25519 gate: the cart mandate is verified before any detector runs; one changed byte fails closed. Three detectors run in parallel: constraints use arithmetic and rules, drift compares buyer reasoning with original intent using local embeddings, and injection scans merchant messages for instruction hijacks. Policy decision: only this structured signal bundle, never the raw transcript, reaches the policy layer.

Policy decides the response.

Same negotiation, same signals, different policy.

A strict B2B receivables policy and a consumer quick-commerce policy can set different risk tolerances for the same drift score. Since the policy layer sees only the signal bundle, re-evaluation is a pure function over computed signals: no negotiation replay and no new model calls.

Judgment stays human.

A real STEPUP transaction pauses for review rather than being forced through by a pattern score.

Hard-rejecting every ambiguous case would block legitimate negotiations where prices move, substitutions happen, or bundles are proposed. STEPUP is for negotiations suspicious enough to pause but not clear-cut enough to reject: a human gets the full context, what changed, which constraint is affected, and why the system did not auto-reject.
